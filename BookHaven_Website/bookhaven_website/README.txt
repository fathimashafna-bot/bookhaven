BOOKHAVEN WEBSITE — QUICK START

1. Extract the ZIP folder.
2. Open the `bookhaven_website` folder in Visual Studio Code.
3. Open `index.html` in a browser.

Recommended: install the "Live Server" extension in VS Code, then right-click
index.html and choose "Open with Live Server".

WHAT IT DOES
- Searches the live Open Library catalogue by book title, author, or genre.
- Shows book covers when available, author, first publication year, subject/genre,
  and rating data when available.
- Sorts by best match, highest rating, or title.
- Lets you save books to "My shelf" using local browser storage.
- Includes quick genre buttons and a responsive layout for phones and computers.

IMPORTANT
- Internet access is needed for live book search and book covers.
- Ratings are not available for every book.
- This is a front-end website, so saved books stay in the same browser on the same
  device. A real account/login system would require a backend and database.
